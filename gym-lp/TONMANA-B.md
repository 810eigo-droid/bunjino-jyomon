# トンマナ定義書【B案専用】(ヘルスライフジム仮称・群馬3号店LP)

最終更新: 2026-09-03
対象: `gym-lp/index-v2.html`(B案・大人シック・参考LP寄せ)
このファイルだけでB案の画像制作・バナー制作・写真選定が完結する。

## 1. コンセプト

**「何歳からでも、体は変わる。」**

- 業態: 続けられるパーソナルジム(完全マンツーマン・月額14,900円〜)
- 方向性: **力強く、引き締まった、大人の熱量**。本家LP(healthlife-gym.com/lp1)の
  黒×赤の雰囲気を引き継ぎつつ、下品にならないよう質感で品を保つ
- ターゲットは30〜70代。暗くても文字は大きく・コントラストは高く(高齢者対応)
- キーワード: 変化/本気/信頼/マンツーマン/続けられる
- 避けるもの: かわいい・ポップ・パステル・丸ゴシック・絵文字・細い文字

## 2. カラーパレット

| 役割 | 色名 | HEX | 使いどころ |
|---|---|---|---|
| 地色(暗) | 墨茶 | `#221A13` | FV・料金・CTA帯の背景 |
| 地色(明) | 白 | `#FFFFFF` | コンテンツのカード面 |
| 地色(中) | 生成りグレー | `#F5F0E8` | ページの地、カードの下地 |
| メイン | オレンジ | `#F07818` | グラデの起点、アクセント |
| メイン濃 | 赤 | `#D93A0C` | グラデの終点、価格、強調 |
| グラデ | ─ | `#F58A1F → #E4520E`(120deg) | 見出し帯、価格面、申込ボタン |
| アクセント | 金茶 | `#E8A33D` | 暗い地の上のラベル・罫線・タグ専用 |
| CTA | ゴールド | `#E8A33D`(文字は墨茶) | 電話・予約ボタン ※原色の緑は使わない(2026-09-03変更) |
| LINE | LINE緑 | `#06C755` | 【入会待ちLINE】ボタン専用(ブランドカラーのため例外的に維持) |
| 文字 | 墨 | `#251C15` | 白地の本文(真っ黒は使わない) |
| 文字淡 | 灰茶 | `#6E5F4E` | 注記、補足 |

**配色ルール**
- 暗い帯(墨茶)でFV・料金・CTAを挟み、間のセクションは白系で明るく
- オレンジ→赤のグラデは「ここぞ」の面(価格・申込ボタン・見出し帯)だけ
- 金茶は暗い地の上専用。白地には使わない
- 禁止色: 青・紫・ピンク・パステル全般

## 3. 書体

| 用途 | フォント | ウェイト |
|---|---|---|
| 見出し・本文 | Noto Sans JP | 見出し900 / 本文400〜500、強調700 |
| 数字・価格・欧文ラベル | Oswald | 600 |

- 丸ゴシックは使わない。細いウェイトも使わない
- 本文17px以上相当・行間広め(高齢者対応)。バナーでも小さい文字を詰め込まない
- 価格の数字は特大(周囲の文字の2倍以上)で「16,900円→14,900円」の落差を見せる

## 4. あしらい・モチーフ

- **斜めのグラデスラッシュ**: FV背景に右上から差し込むオレンジ〜赤の光(不透明度15〜20%)
- **細いグラデライン**(高さ4〜6px): セクション区切り
- 角丸は小さめ(4〜10px)。pill型・大きな角丸は使わない
- 影は黒系で深め。暗い帯の上の白カードはしっかり浮かせる
- ラベル・タグは四角ベース(暗い地+金茶文字、または白地+墨文字)
- 絵文字不使用。アイコンは線画SVG

## 5. 写真のトーン(選定・撮影・レタッチ基準)

- 窓からの自然光+やや暗めの引き締まった店内。オレンジの間接照明の気配
- コントラスト高め・シャドウは締める(A案のような白飛びの明るさにはしない)
- **人物は笑顔のシニア〜ミドル世代**(60〜70代を必ず含める)。真剣な表情もOKだが苦しそうな表情はNG
- トレーナーとのマンツーマン場面を優先。服装は落ち着いた色のスポーツウェア
- NG: ネオン、青白い照明、若者だけの構図、汗だくのハードトレーニング、ビキニ系ビフォーアフター

## 6. 文言のトーン

- 語りかけ口調・ですます調。「〜しませんか?」「大丈夫です」「おまかせください」
- 難しいカタカナ語を避ける(「サブスク」→「月額だけ」など)。「パーソナル」「マンツーマン」はOK
- 不安の先回り: 「はじめてでも」「何歳からでも」「無理なく」を随所に
- キャンペーンは具体的な数字と締切で: 「9/20(日)まで」「16,900円→14,900円」「永年」「今回限り」

## 7. 画像生成プロンプト(ChatGPT等用)

### FV背景(SP用・PC用の2枚セット)

生成した画像は以下のファイル名で `gym-lp/images/` に置くだけで、
`index-v2.html` のFV背景に自動で適用される(無い間はCSSグラデで表示)。

| ファイル名 | サイズ | 適用範囲 |
|---|---|---|
| `images/fv-bg-b.webp` | 縦長 1080×1600 | スマホ(〜839px) |
| `images/fv-bg-b-pc.webp` | 横長 1920×1080 | PC(840px〜) |

- 上に載る要素: 白のキャッチコピー(中央)、写真枠、バッジ、オレンジ〜赤グラデのキャンペーン枠、緑のLINE/電話ボタン
- そのため背景は「暗く・うるさくなく・中央は空ける」が絶対条件
- 書き出しはWEBP・1枚150〜250KB目安に圧縮

SP用(fv-bg-b.webp):

```
パーソナルジムのランディングページのファーストビュー用の背景画像を
生成してください。
【用途】上に白いキャッチコピー・写真・申込ボタンを載せるため、
暗めで主張しすぎない背景。
【構図】焦げ茶〜黒(#221A13)の暗い縦長の地。右上の角から斜めに
オレンジ(#F07818)〜赤(#D93A0C)のグラデーションの光のスラッシュが
1〜2本うっすら差し込む(不透明度15〜20%)。左下の角にも同系の光をごく弱く。
中央の縦長の帯(画面の6割)は暗いまま完全に余白として空ける。
【質感】マットで引き締まった質感。ジムの空気感(コンクリートの壁・
金属の気配)をごく薄く感じる程度。ぼかし気味でディテールは立てない。
【禁止】文字入れ、人物、器具のはっきりした描写、青・紫、明るいパステル、
丸くかわいい要素、ネオン、テカリのある3D質感、白背景。
【サイズ】縦長 1080×1600
```

PC用(fv-bg-b-pc.webp): 上記と同じで【構図】と【サイズ】だけ変更:

```
【構図】焦げ茶〜黒(#221A13)の暗い横長の地。左右の両端から中央に向かって
オレンジ(#F07818)〜赤(#D93A0C)のグラデーションの光のスラッシュが
斜めにうっすら差し込む(不透明度15〜20%)。
中央の広い範囲(横幅の6割)は暗いまま完全に余白として空ける
(コピーとキャンペーン枠が中央に載るため)。
【サイズ】横長 1920×1080
```
