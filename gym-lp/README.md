# ヘルスライフジム(仮称)群馬3号店 新規オープンLP デザイン案

群馬に3店舗目をオープンするジムの集客用ランディングページのデザイン案です。
`gym-lp/index.html` をブラウザで開くとそのまま確認できます(スマホ優先・レスポンシブ対応)。

※参考ページ https://healthlife-gym.com/lp1 は作業環境から閲覧できなかったため、
相談内容(オレンジ基調・高齢者にも響く・スマホ優先・キャンペーン価格)をもとに構成しています。
参考ページに寄せる調整が必要なら、スクリーンショットをいただければ反映できます。

## デザインコンセプト

- **配色**: 黄・オレンジ系(ポップ・にぎやか)+高齢者にも読みやすい高コントラスト
  - だいだい `#F0761B` = メインカラー・見出しアクセント
  - 山吹 `#FFC42E` = バッジ・マーカー・しましまディバイダー
  - 深柿 `#C74A05` = 価格・申込CTA・強調(いちばん目立つ色)
  - クリーム `#FFF6E8` = ページの地色 / 白 = カード面
  - 緑 `#2F7D5B` = 電話ボタン・「安心」系チップのみ(信頼の差し色)
- **書体**: 見出し・数字 = Zen Maru Gothic(丸ゴシック=ポップで柔らかい)/ 本文 = Noto Sans JP
  - 本文17px・行間1.9と大きめ設定。細いウェイトは不使用(高齢者対応)
- **CV導線**: FV直下キャンペーン枠 → 料金セクション → お問い合わせ、
  さらに画面下に固定の「電話する/見学を予約」バー(スマホで常時表示)

## 画像の入れ方(すべてWEBP)

`gym-lp/images/` に以下のファイル名で入れるだけで、プレースホルダーと自動で差し替わります。

| ファイル名 | 用途 | 推奨サイズ |
|---|---|---|
| `images/fv-main.webp` | FVメイン写真(店内・トレーニング風景) | 1200×700 |
| `images/reason-01.webp` | 理由1: マシン | 800×450 |
| `images/reason-02.webp` | 理由2: スタッフ | 800×450 |
| `images/reason-03.webp` | 理由3: 料金・受付 | 800×450 |
| `images/reason-04.webp` | 理由4: 店舗外観 | 800×450 |
| `images/store-new.webp` | 新店舗の外観 | 1200×500 |

- ロゴ: ヘッダーの「LOGO支給」枠を支給ロゴに差し替え
- 容量目安: 1枚100〜200KB(スマホ優先のため)

## 納品時にやること

1. CSS内「WATERMARK」ブロックを削除(Sample透かしが消える)
2. `<meta name="robots" content="noindex">` を削除(検索に載せる場合)
3. 電話番号 `tel:0000000000`(4箇所)・mailtoを実データに差し替え
4. 地図iframeを新店舗住所のものに差し替え
5. サイト公開(リリース)作業 ※ご要望に含まれるためサーバー情報の共有が必要
