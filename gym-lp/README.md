- **配色**: 黄・オレンジ系(ポップ・にぎやか)+高齢者にも読みやすい高コントラスト

  - 緑 `#2F7D5B` = 電話ボタン・「安心」系チップのみ(信頼の差し色)
- **書体**: 見出し・数字 = Zen Maru Gothic(丸ゴシック=ポップで柔らかい)/ 本文 = Noto Sans JP
  - 本文17px・行間1.9と大きめ設定。細いウェイトは不使用(高齢者対応)
- **CV導線**: FV直下キャンペーン枠 → 料金セクション → お問い合わせ、

## 納品時にやること

1. CSS内「WATERMARK」ブロックを削除(Sample透かしが消える)
2. `<meta name="robots" content="noindex">` を削除(検索に載せる場合)
3. 電話番号 `tel:0000000000`(4箇所)・mailto・LINE URL `lin.ee/XXXXXXXX`(3箇所)を実データに差し替え
4. 地図iframeを新店舗住所のものに差し替え
