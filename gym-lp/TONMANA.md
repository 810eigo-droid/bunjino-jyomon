# トンマナ定義書(ヘルスライフジム仮称・群馬3号店LP)

最終更新: 2026-09-03
画像制作・バナー制作・写真選定の際はこのルールに合わせる。

> **重要**: このLPはA案・B案の2案あり、トンマナが異なる。
> このファイルの**セクション1〜7はA案(明るいオレンジ×ポップ)基準**。
> **B案の画像を作るときは単独ファイル `TONMANA-B.md` を使うこと**(セクション9は同内容の抜粋)。

## 1. コンセプト

**「何歳からでも、体は変わる。」**

- 業態: **続けられるパーソナルジム**(完全マンツーマン・月額14,900円〜)。
  本家LP(healthlife-gym.com/lp1)は黒×赤の熱量系だが、
  新店LPはご相談どおり**明るいオレンジ×高齢者フレンドリー**に振る
- 明るい・元気・にぎやか。ただし若者向けのスタイリッシュ系ではなく、
  **30〜70代が「自分の場所だ」と感じる親しみやすさ**が最優先
- キーワード: 朝日/健康/笑顔/安心/マンツーマン/続けられる/地元(群馬)
- 避けるもの: 暗い・ストイック・筋肉ゴリゴリ・英語多用・細い文字
- 本家から踏襲する要素: 会員様の声、人気の理由、体験カウンセリング(無料)訴求、
  スタッフ紹介、緑のCTAボタン、電話番号の大きな表示

## 2. カラーパレット

| 役割 | 色名 | HEX | 使いどころ |
|---|---|---|---|
| メイン | だいだい | `#F0761B` | 見出しアクセント、アイコン、罫線、番号マーク |
| メイン淡 | うすだいだい | `#FDE3C8` | 面の塗り、写真の下地、プレースホルダー |
| 強調 | 深柿 | `#C74A05` | 価格、締切、申込ボタン(**最も目立たせたい所専用**) |

| サブ淡 | クリーム淡黄 | `#FFF1C9` | ラベルの地、キャンペーン枠の地 |
| 地色 | クリーム | `#FFF6E8` | ページ・画像の背景 |
| 文字 | 焦茶 | `#40301F` | 本文、見出しの基本色(真っ黒は使わない) |
| 文字淡 | 灰茶 | `#7A6852` | 注記、補足 |
| 差し色 | 緑 | `#2F7D5B` | 電話ボタン、「安心・無料」系チップ**のみ**。多用禁止 |

**配色ルール**
- 面積比の目安: クリーム・白 6 / だいだい・山吹 3 / 深柿・緑 1
- 深柿はCTA・価格・締切だけ。あちこちに使うと締まらなくなる
- 緑は「安心/信頼/無料」の意味がある場所だけ
- 禁止色: 青・紫・ピンク・ビビッドレッド・真っ黒背景

## 3. 書体

| 用途 | フォント | ウェイト |
|---|---|---|
| 見出し・数字・ボタン | Zen Maru Gothic | 900(基本)/ 700 |
| 本文 | Noto Sans JP | 400〜500、強調700 |

- 丸ゴシック=ポップで柔らかい印象、の統一。明朝・細ゴシックは使わない
- 高齢者対応: 本文17px以上相当・行間広め・高コントラスト。バナーでも小さい文字を詰め込まない
- 価格などの数字は特大(周囲の文字の2倍以上)で「16,900円→14,900円」の落差を見せる

## 4. あしらい・モチーフ

- **朝日の放射線**: FV背景にうすいオレンジの放射(元気・健康の象徴)
- **しましま(テント地)**: だいだい×山吹の斜めストライプ。セクション区切りに使用
- **角丸**: ボタンは丸(pill型)、カードは角丸14〜20px。鋭角は使わない
- **点線・破線**: 区切り線はオレンジの破線(手作り感・親しみ)
- バッジは白地+オレンジ縁 or 山吹地+焦茶文字
- 影は薄く(焦茶の8〜20%程度)。ドロップシャドウのやりすぎ禁止

## 5. 写真のトーン(選定・撮影・レタッチ基準)

- 明るい自然光・暖色寄り。白飛びぎみに明るく、影は柔らかく
- **人物は笑顔のシニア〜ミドル世代**(60〜70代を必ず含める)。モデル然としすぎない自然な表情
- 服装はカラフルすぎない普段着のスポーツウェア
- 構図はゆったり(余白を残す)。マシンのアップより「人が使っている場面」
- NG: 暗いジム、ネオン、汗だくのハードトレーニング、若者だけの写真、クール系の青白い照明

## 6. 文言のトーン

- 語りかけ口調・ですます調。「〜しませんか?」「大丈夫です」「おまかせください」
- 難しいカタカナ語を避ける(「サブスク」→「月額だけ」、「パーソナル」→「マンツーマン」)
- 不安の先回り: 「はじめてでも」「何歳からでも」「無理なく」を随所に
- キャンペーンは具体的な数字と締切で: 「9/20(日)まで」「16,900円→14,900円」「永年」「今回限り」

## 7. 画像生成プロンプト(ChatGPT等用)

### FV背景(fv-main.webp の代わりに背景として使う場合)

```
フィットネスジムのランディングページ用の背景画像を生成してください。
【用途】上にキャッチコピーと写真を載せるため、主張しすぎない明るい背景。
【構図】クリーム色(#FFF6E8)の地に、画面上部中央から朝日のような
うすいオレンジ(#F0761B 不透明度10%程度)の放射線が広がる。
下部の四隅にだけ、ダンベル・シューズ・タオルなどの運動モチーフを
線画でうっすら(不透明度15%程度)配置。中央は余白として空ける。
【色】クリーム #FFF6E8、だいだい #F0761B、山吹 #FFC42E、焦茶 #40301F。
【質感】フラットでマット。紙のような温かい質感。
【禁止】文字入れ、人物、青・紫・ピンク、黒背景、テカリのある3D質感、
暗い色調、ネオン、写実的すぎる描写。
【サイズ】縦長 1080×1350(スマホFV用)
```

## 9. B案(大人シック・参考LP寄せ)のトンマナ

`index-v2.html` 用。ポップさを抑え、力強く引き締まった方向。

### カラーパレット(B案)

| 役割 | 色名 | HEX | 使いどころ |
|---|---|---|---|
| 地色(暗) | 墨茶 | `#221A13` | FV・料金・CTA帯の背景 |
| 地色(明) | 白 | `#FFFFFF` | コンテンツセクションのカード面 |
| 地色(中) | 生成りグレー | `#F5F0E8` | ページの地、カードの下地 |
| メイン | オレンジ | `#F07818` | グラデの起点、アクセント |
| メイン濃 | 赤 | `#D93A0C` | グラデの終点、価格、強調 |
| グラデ | | `#F58A1F → #E4520E`(120deg) | 見出し帯、価格面、申込ボタン |
| アクセント | 金茶 | `#E8A33D` | 暗い地の上のラベル・罫線・タグ |
| CTA | 緑 | `#1FA84F` | 電話・予約ボタン(参考LP踏襲) |
| LINE | LINE緑 | `#06C755` | 【入会待ちLINE】ボタン専用(変更不可) |
| 文字 | 墨 | `#251C15` | 白地の本文 |

- 配色ルール: 暗い帯(墨茶)でFV・料金・CTAを挟み、間は白系で明るく。
  オレンジ〜赤のグラデは「ここぞ」の面にだけ。金茶は暗い地の上専用
- A案との違い: クリーム地・山吹・しましま・pill型・絵文字は**使わない**

### 書体(B案)

- 見出し・本文: Noto Sans JP(見出しは900、細いウェイト不使用)
- 数字・価格・欧文ラベル: Oswald(600)
- 丸ゴシック(Zen Maru Gothic)は**使わない**

### あしらい(B案)

- 角丸は小さめ(4〜10px)。pill型・大きな角丸は使わない
- 斜めのグラデスラッシュ(FV背景)、細いグラデライン(区切り)
- 影は黒系で深め(暗い帯の上のカードは浮かせる)
- 絵文字不使用。アイコンは線画SVG

### 画像生成プロンプト(B案用)

FV背景:

```
パーソナルジムのランディングページ用の背景画像を生成してください。

【構図】焦げ茶〜黒(#221A13)の暗い地に、右上から斜めに
オレンジ(#F07818)〜赤(#D93A0C)のグラデーションの光やスラッシュが
うっすら差し込む(不透明度15〜20%)。中央〜左は暗いまま余白として空ける。
【質感】マットで引き締まった質感。ジムの空気感(コンクリート・金属の気配)を
ごく薄く感じる程度。
【禁止】文字入れ、人物、青・紫、明るいパステル、丸くかわいい要素、
ネオン、テカリのある3D質感。
【サイズ】縦長 1080×1350(スマホFV用)
```

バナー・SNS告知画像:

```
パーソナルジムのオープン告知バナーを生成してください。
```
