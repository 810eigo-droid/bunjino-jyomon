# ぶんじの縄文探偵団 LP デザイン案

国分寺市の地域サークル「ぶんじの縄文探偵団」のランディングページ(LP)デザイン案です。
`index.html` をブラウザで開くとそのまま確認できます(モバイル重視・レスポンシブ対応)。

## デザインコンセプト

- **配色**: 茶系(自然・モダン・高級感)。生成り `#F4ECDC` →砂色 `#E4D2AC` のグラデを地に、焦茶 `#3A2A1C` で締める
  - 差し色ルール: **深緑(松葉)`#3F5A44`** = ラベル・タグ・小見出し / **ペールグリーン `#DDE6D5`** = 注記・チップの面 / **エンジ(蘇芳)`#8C3A3F`** = CTAボタンと日付だけ / **金茶 `#A8873C`** = 罫線・縁取り・価格(高級感の要)
- **書体**: ブロック体不使用の総明朝。見出し = Zen Old Mincho / 本文 = Shippori Mincho(Medium)/ 数字・欧文 = Cormorant Garamond(Google Fonts)
- **モチーフ**: 恋ヶ窪出土の土偶シルエット(SVG)と縄目パターンを全体に使用
- 各セクションを発掘調査に見立てて「調査区 01〜07」とラベリング

## セクション構成(ご要望との対応)

| 調査区 | セクション | 実装想定 |
|---|---|---|
| FV | メインビジュアル(恋ヶ窪の土偶) | HTML or 画像 |
| 01 | 探偵団の紹介 | HTML |
| 02 | イベント告知(月1〜2回) | WPブロックで再現可能なシンプル構成 |
| 03 | イベント報告(写真・コメント) | WPブロックで再現可能なカード3枚 |
| 04 | 過去イベントギャラリー | 正方形グリッド + Instagramリンク |
| 05 | じょうもんMAP・資料 | 地図画像 + PDFリンク一覧(資料は同セクションに統合) |
| 06 | グッズ販売 | ミニギャラリー + BASEリンクボタン |
| 07 | お問い合わせ | WPで再現できる仮フォーム(現状は mailto) |

## 画像の入れ方(すべて WEBP)

`images/` フォルダに以下のファイル名・サイズで入れるだけで、自動的にプレースホルダーと差し替わります。
画像がない間は縄目パターン+土偶のプレースホルダーが表示されます。

| ファイル名 | サイズ(px) | 用途 |
|---|---|---|
| `images/fv-dogu.webp` | 800×1000(縦) | FV:恋ヶ窪の土偶 |
| `images/about.webp` | 800×600 | 紹介:活動風景(まち歩き集合写真など) |
| `images/report-01.webp` | 800×600 | 報告1:8/23 くにたち郷土文化館 |
| `images/report-02.webp` | 800×600 | 報告2:7/19 ZINE編集会議 |
| `images/report-03.webp` | 800×600 | 報告3:6月 原画展コラボ |
| `images/gallery-01.webp` 〜 `gallery-06.webp` | 600×600(正方形) | 過去イベントギャラリー |
| `images/map.webp` | 800×600 | じょうもんMAPのプレビュー |
| `images/goods-01.webp` 〜 `goods-04.webp` | 600×600(正方形) | グッズ(ZINE・缶バッジ・ステッカー・資料) |

- 容量目安: 1枚 100〜200KB 程度に圧縮するとモバイルで軽快です
- 枚数は増減できます(ギャラリー・グッズは2〜8枚まで自然に対応)

## 仮置きしている情報(要差し替え)

- イベント日程・レポート文はチラシ(2025年予定)から引用した仮テキスト
- グッズの品名・価格はダミー
- PDFリンク・BASEショップURLは未設定(`#`)
- お問い合わせフォームは mailto の仮実装(WP移行時にフォームプラグイン等で置き換え想定)
